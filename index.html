    Help

    This help explains each section in order: its layout from top to bottom (the order you reach things with Tab), its buttons, and its commands. Hotkey mode is on by default, so single keys reach the console instead of NVDA or JAWS. If a key does not respond, press F2 twice, or press NVDA+Space for focus mode. The buttons work in any mode.

    1. Playlist

    The main section. It has three playlists, which you can use for songs, jingles and ads. Layout from top to bottom:

    1. Playlist tabs. Playlist 1, 2 and 3, each with its number of files.
    2. New on this playlist. A button that opens the file chooser to add songs, jingles and ads. You can also drop files on the page.
    3. Files list. Appears after you add files. Shows the files of this playlist in order.
    4. Now playing. The status, the title, the next track, the elapsed and the remaining time.
    5. Player button. One button that controls the music with single keys.
    6. Playlist tools. Add a folder, Add playlist, Remove this playlist, Clear this playlist.

    Playlist tabs

    Right Ctrl
    Next playlist
    Left Ctrl
    Previous playlist
    Home, End
    First or last playlist

    Files list

    Right Ctrl
    Next file
    Left Ctrl
    Previous file
    Enter
    Open the file menu: Delete, Adjust position, Cancel
    Adjust position
    Move to the place you want with Left or Right Ctrl, then Enter. Escape cancels.
    Escape
    Close the file menu

    Player button

    P
    Play, press again to stop
    Shift+P
    Previous track
    N
    Next track
    R
    Repeat: off, playlist, track
    S
    Shuffle on or off
    M
    Mute
    + and -
    Volume up or down
    Left, Right
    Back or forward 10 seconds
    I
    Read what is playing, with the times

    Playlist tools

    Add a folder
    Adds every audio file in a folder
    Add playlist
    Makes one more playlist
    Remove this playlist
    Removes the playlist you are on
    Clear this playlist
    Deletes all its files

    2. Hotkey sounds

    For short sounds you want on a single key, such as a jingle or a sound effect. It has only two buttons. Layout from top to bottom:

    1. Assign or customize. Puts a sound on a key, and changes it later.
    2. Play sounds. The one place where the keys play their sounds.
    3. Assigned keys. A line of text that lists your keys and their sounds.

    Assign or customize

    Type a letter or number
    A free key opens the file chooser. Pick a file and it is assigned, then the Customize panel opens.
    Key already used
    You get Replace, Customize and Cancel.
    Use the selected playlist track
    Gives the key the file selected in the playlist instead of a new file.

    Customize panel

    Volume
    How loud this sound is
    Speed
    Slower or faster, from half to double
    Fade in, Fade out
    Seconds to rise or fall
    Play alone
    Stops the music and the other sounds while this one plays
    Resume afterwards
    The music continues from where it stopped. Needs Play alone.
    Test sound, Remove this key, Done
    Try it, clear the key, or save and close

    Play sounds

    Assigned key
    Play its sound. Press again to stop it.
    Hold the key + Up, Down
    Volume of that sound, live
    Hold the key + Left, Right
    Speed of that sound, live
    Escape
    Stop everything

    Sounds are saved in this app and stay after you close it. The keys play only while you are on the Play sounds button.

    3. Settings

    Choices that stay the same until you change them. Layout from top to bottom, in three groups:

    Sound

    Volume
    Master volume. Left and Right arrows change it.
    Crossfade
    Seconds where one track fades into the next
    Mute output
    Silence everything
    Lower the music
    The music gets quieter while a hotkey sound plays

    Playback

    Repeat
    Off, whole playlist, or current track
    Shuffle
    Random order
    Voice announcer
    Says each track title on air
    Announce the time
    Says the time at the top of every hour

    Keyboard

    Hotkey mode
    Every key reaches the console, even with NVDA or JAWS. F2 toggles it. It turns off heading navigation.

    4. Help

    This section. Layout from top to bottom:

    1. The explanation of each section, starting with Playlist.
    2. Keys that work everywhere.
    3. Message history. The latest messages the console has said, newest first, so you can read one again.

    Keys that work everywhere

    Left, Right on a section tab
    Switch between Playlist, Hotkey sounds, Settings and Help
    Esc
    Stop the music and all hotkey sounds
    F2
    Hotkey mode on or off
    Ctrl+Shift+U
    Check for updates. The desktop app also checks by itself when it opens.
